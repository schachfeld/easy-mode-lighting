# Glow for Home Assistant

Add this app repository to Home Assistant:

`https://github.com/schachfeld/easy-mode-lighting#home-assistant`

Then install **Glow**, start it, and enable **Show in sidebar**. New published versions appear as normal app updates.

[Source and release notes](https://github.com/schachfeld/easy-mode-lighting)

This branch is generated by the release workflow. Do not edit it by hand.
